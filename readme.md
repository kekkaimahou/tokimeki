# tokimeki: (extensible) mudae-focused selfbot
## Disclaimer
Utilizing self-bots is against Discord's TOS. Use this project at your own risk. The developers and contributors are not responsible for any issue regarding your account.
---
## setup guide
Prerequisites: Python 3.11 or higher installed and pip available
First, `git clone` or download the source code available in this repository.
Then, install the required dependencies:
`pip install -r requirements.txt`
Following that, set the TOKEN environment variable equal to your discord user token.
*(Instructions for setting environment variables is operating system-dependent: search online if you don't know how to do so)*
After that, run `bot.py` to login to your account.
