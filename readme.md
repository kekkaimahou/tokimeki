## setup guide
- Prerequisites: Python 3.11 or higher installed and pip available
- First, `git clone` or download the source code available in this repository.
- Then, install the required dependencies:
`pip install -r requirements.txt`
- Following that, set your user token in `config.toml` or pass your token with the `--token` argument.
- After that, run `bot.py` to login to your account.
